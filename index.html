INTERVIEW READY

Explain it in 30 seconds

A browser sends an HTTP request to the EC2 public IP on port 80. The security group permits the traffic, and NGINX listens on the instance, finds the requested static files and returns an HTTP response. The browser then renders HTML, applies CSS, runs JavaScript and loads images.
